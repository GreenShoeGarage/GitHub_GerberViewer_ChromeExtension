Gerber Viewer for GitHub

Settings

Defaults

These apply when the preview panel first appears on a page.

Network

GitHub's unauthenticated API allows 60 requests per hour. If you browse hardware repos heavily, you may hit this limit.

Diagnostics

If you encounter a problem, you can copy a diagnostic blob to your clipboard. It contains the extension version, browser info, and a log of recent events. No data is sent anywhere by this button: it just writes to your clipboard so you can paste it into a bug report.

What does the diagnostic blob contain?
  • Extension version
  • Your browser's user-agent string
  • The most recent ~50 events the extension recorded on the current page (activations, file loads, errors)
  • For errors: the category, summary, and underlying error message if any

It does not contain file contents, full repository URLs, your GitHub credentials, or any personally identifying information beyond what is in the URL of the page that triggered an event.

Reset

Restore all settings to their defaults.
